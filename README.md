# NayePankh Foundation Website

## Project Overview

This project is a responsive website developed for NayePankh Foundation as part of a Web Development Internship application. The website is designed to showcase the foundation's mission, programs, volunteer opportunities, and community impact in a user-friendly and visually appealing manner.

## Features

* Responsive Design for Desktop, Tablet, and Mobile Devices
* Home Page with Introduction
* About Us Section
* Programs and Initiatives Section
* Statistics Counter
* Gallery Section
* Testimonials Section
* Volunteer Registration Form
* Contact Information Section
* Smooth Navigation and User-Friendly Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

NayePankh Foundation Website

* index.html
* style.css
* script.js
* images (if applicable)

## Objective

The objective of this project is to create an informative and accessible platform that highlights the activities and goals of NayePankh Foundation while demonstrating front-end web development skills.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any modern web browser.
4. The website will load locally without requiring additional setup.
